## 🎬 Animation Philosophy

All animations follow these principles:

**Elastic Spring Feel**
- Uses: `cubic-bezier(0.34, 1.56, 0.64, 1)`
- Effect: 56% overshoot for playful bounce
- Used for: Bar animations, bouncing elements

**Smooth Professional Ease**
- Uses: `cubic-bezier(0.42, 0, 0.58, 1)`
- Effect: Natural without overshoot
- Used for: Line drawing, reveal animations

**Heartbeat Bounce**
- Uses: `cubic-bezier(0.68, -0.55, 0.265, 1.55)`
- Effect: Multiple oscillations
- Used for: Heart animations, pulse effects

**Stagger Timing**
- 0.05s: Barely noticeable
- 0.1s: Clear sequence
- 0.15s: Strong cascade
- 0.3s: Creates rhythm

**Result:** Professional choreography that guides user attention
