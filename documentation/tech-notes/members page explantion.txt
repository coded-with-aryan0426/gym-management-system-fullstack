### Detailed Components

#### A. **Membership Status Card** (Top Priority)
**Why:** Most important info - is membership active?
```
Display Elements:
├── Status Badge: ACTIVE (green) / EXPIRING (yellow) / EXPIRED (red)
├── Plan Name: "Premium Monthly"
├── Days Remaining: "25 days left"
├── Expiry Date: "Expires: April 20, 2024"
└── Action Button: [Renew Now] (if < 7 days)
```

**Alert States:**
- **Active (>7 days)**: Green background, normal display
- **Expiring Soon (<7 days)**: Yellow/orange alert, "Renew Now" button
- **Expired**: Red alert, "Renew Membership" prominent button

#### B. **Quick Stats Cards**
**Purpose:** At-a-glance metrics

```
Classes This Week:
├── Icon: 📅
├── Number: Large font (3)
├── Label: "Classes This Week"
└── Subtext: "2 more scheduled"

Attendance This Month:
├── Icon: ✅
├── Number: 18
├── Label: "Attended"
├── Progress vs Last Month: "↑ +3 from last month"

Workout Streak:
├── Icon: 🔥
├── Number: 7
├── Label: "Day Streak"
└── Motivational text: "Keep it up!"
```

#### C. **Upcoming Classes Section**
**Shows next 3-5 booked classes**

```
Each Class Entry:
├── Date & Day: "Tomorrow - Tuesday, March 26"
├── Class Icon: 🧘 (based on class type)
├── Time: "9:00 AM"
├── Class Name: "Yoga Class"
├── Location: "Room A"
├── Trainer: "With Sarah Johnson"
├── Actions:
│   ├── [View Details] → Opens class info modal
│   └── [Cancel Booking] → Confirmation then cancel
```

**Empty State:**
```
┌──────────────────────────────────────┐
│      📅 No Upcoming Classes          │
│                                      │
│   You don't have any classes booked  │
│                                      │
│     [Browse Available Classes]       │
└──────────────────────────────────────┘
```

#### D. **My Trainer Section**
```
Display:
├── Trainer Photo/Avatar
├── Trainer Name: "John Smith"
├── Specialization: "Weight Training & Nutrition"
├── Rating: ⭐⭐⭐⭐⭐ (if applicable)
├── Next Session Info:
│   ├── Date: "Friday, March 29"
│   ├── Time: "10:00 AM"
│   └── Duration: "60 minutes"
└── Action Buttons:
    ├── [Message Trainer] → Opens chat/message form
    └── [View Full Profile] → Trainer details page
```

**If No Trainer Assigned:**
```
┌──────────────────────────────────┐
│   🏋️ No Trainer Assigned        │
│                                  │
│   Want personal training?        │
│   [Request Trainer Assignment]   │

```

#### E. **Progress Snapshot**
**Mini version of full progress tracking**

```
Weight Progress:
├── Visual: Progress bar

### Key Points for Mobile View

```
Desktop (> 1024px):
├── Sidebar always visible
├── Multi-column layouts
├── Larger cards and images
└── More info per screen

Tablet (768px - 1024px):
├── Collapsible sidebar
├── 2-column layouts mostly
├── Slightly smaller cards
└── Maintained functionality

Mobile (< 768px):
├── Hamburger menu for navigation
├── Single column layout
├── Stacked cards
├── Bottom navigation bar
├── Larger touch targets (48px min)
├── Simplified charts
└── Mobile-optimized modals
