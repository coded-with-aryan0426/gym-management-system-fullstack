## 📊 SUMMARY - ICON FREQUENCY

### Most Used Icons (Reused across roles):
- **LayoutDashboard** - Owner/Member dashboard
- **Calendar** - Classes/Schedule (Owner, Trainer, Member)
- **CreditCard** - Payments/Membership (Owner, Member)
- **User** - Profiles (Trainer, Member)
- **Bell** - Notifications (All roles)
- **Settings** - Configuration (All roles)
- **UserCheck** - Attendance/Progress (Owner, Trainer)
- **Users** - Member/Class lists (Trainer, Member)
- **TrendingUp** - Progress/Analytics (Trainer, Member)
- **BarChart** - Reports & Analytics (Owner, Trainer)

### Custom Icons Created:
- **MembersGroupIcon** - Owner Members page
- **TrainersGroupIcon** - Owner Trainers page
- **StaffGroupIcon** - Owner Staff page
